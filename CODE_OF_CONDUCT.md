# Code of Conduct

- Be respectful and direct. Critique code, not people.
- Reviews are about the work: explain the "why", suggest the fix.
- Ask early when blocked; nobody should wait silently.
- Own what you merge, whether you or an agent typed it.
- Protect candidate and customer data as if it were your own.
- Report security issues privately to security@hellosmart.ai; report conduct issues to Product Delivery or the Team Lead.

Harassment or discrimination of any kind is not tolerated.
