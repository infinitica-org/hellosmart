| Term | Meaning |
|---|---|
| **Add-on** | A paid extra such as own routing, white label, custom templates or AI credits. |
| **AI proxy** | The only route by which a workspace's AI calls reach providers. |
| **Assessment** | A company's configured copy of a template. Called a "task" in the screens. |
| **Assignment** | One candidate assigned to one assessment. |
| **Audit log** | A permanent record of important actions. |
| **Candidate cap** | The maximum number of candidates a company can use, counted at first workspace launch. |
| **Consent** | The candidate's acceptance of what will be recorded, required before connecting. |
| **Entitlements** | A company's limits and feature switches. |
| **Golden image** | A prebuilt environment image used to start workspaces quickly. |
| **Human in the loop** | People make the final scoring and hiring decisions. |
| **Master login** | The single sign-in page for all roles. |
| **MMP** | Minimum Marketable Product, the first sellable release. |
| **Platform Admin** | HelloSmart's internal administrator. |
| **RBAC** | Role-based access control: what you can see and do depends on your role. |
| **Reviewer agent** | An AI agent that scores one rubric item and cites evidence. |
| **Rubric** | The set of scoring dimensions for an assessment. |
| **SSO** | Single sign-on with Google or Microsoft. |
| **Template** | A versioned blueprint of a task, private to the company it is assigned to. |
| **Time-bound** | The candidate gets a set time from first connect. |
| **Warm pool** | Pre-started workspaces ready to be handed to a candidate. |
| **White label** | Removing HelloSmart's mark and applying the company's own branding. |
| **Window-bound** | The candidate may start only between two dates. |
| **Workspace** | The controlled environment where a candidate works. |
