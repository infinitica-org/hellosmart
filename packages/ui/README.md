# @hs/ui (Company & Admin dept)

Design system: Tailwind + shadcn/ui primitives, tokens from Figma (Product Design). Includes `BrandMark` ("Powered by hellosmart.ai", BR-28), `SafeMarkdown` (rehype-sanitize; the only way to render candidate/brief markdown), form components with built-in labels and error text, and the countdown timer used by the candidate portal.
